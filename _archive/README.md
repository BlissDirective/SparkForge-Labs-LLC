part of the [Full-SparkForge-ReDo](../Full-SparkForge-ReDo.md) cleanup.

**These documents are reference-only. They describe the previous Laboratory
Control Station / Cockpit architecture, which has been scrapped. The active
build target is in `Full-SparkForge-ReDo.md` at the repo root.**

## Do NOT use these for active development

- Cockpit, HeroAnimation, BrandHero3D, HolographicLabMap, and all chrome 3D
  references in these files have been removed from the build target.
- The visual direction is now "Bright & Playful" (light theme, Spark Orange
  + Curious Purple, Fredoka + Nunito type). The dark Frost-Prismatic /
  glassmorphism aesthetic is deprecated.
- Content audits and game enhancement docs still have valid game-level
  findings (bug lists, content expansions) — consult on a case-by-case
  basis if needed, but the architectural recommendations are stale.
