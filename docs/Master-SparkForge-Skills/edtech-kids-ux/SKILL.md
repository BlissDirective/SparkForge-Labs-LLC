# EdTech Kids UX

UX for kids learning platforms: touch targets, cognitive load, parent/teacher surfaces.

## When to use this skill

- Building SparkForge Labs features related to: **EdTech Kids UX**
- Prefer practices that repeated across recent YouTube sources (weighted below).
- Do **not** invent claims from videos without captions; weights come from captioned transcripts only.

## Weighted practice points

- **(weight 8)** Parent / teacher dashboards alongside kid UI
- **(weight 6)** Onboarding with characters / storytelling
- **(weight 5)** Edtech product / platform case patterns
- **(weight 4)** High contrast, playful color systems
- **(weight 3)** Accessibility & inclusive design for kids
- **(weight 2)** Feedback animations & celebration moments
- **(weight 2)** Large tap targets & touch-first UI
- **(weight 2)** Reading level & icon-first labels
- **(weight 1)** Limited cognitive load / progressive disclosure

## SparkForge application notes

- Learning goal first, then mechanics/UI chrome.
- Big targets, short sessions, fail-soft feedback, parent/teacher escape hatches.
- Privacy/COPPA by default; no dark patterns.
