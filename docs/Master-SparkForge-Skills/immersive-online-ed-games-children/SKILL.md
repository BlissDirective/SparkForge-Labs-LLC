# Immersive Online Educational Games for Children

Umbrella skill combining R3F environments, kids UX, game design, and AI literacy for SparkForge Labs.

## Weighted cross-cutting themes

- **(weight 41)** Short feedback loops & celebration of progress
- **(weight 34)** Age-appropriate UX: big targets, low cognitive load
- **(weight 30)** Immersive 3D (R3F/Three) for presence without VR hardware
- **(weight 26)** AI literacy woven into making, not only consuming
- **(weight 24)** Browser/web delivery for access & equity
- **(weight 20)** Playtesting with real kids / teachers
- **(weight 17)** Safety, privacy, parental controls
- **(weight 8)** Character/mascot guided experiences
- **(weight 5)** Scaffolding & progressive challenge
- **(weight 3)** Learning goals before game mechanics / tech

## Hub integration checklist

- Fixed-camera R3F forge lab; HTML panels on meshes for interactive UI.
- PlayStage morph for in-hub light play; heavy games exit/dim forge.
- Age-appropriate UI + COPPA defaults; EscapeFlat for parent/billing.
- AI literacy: making + ethics, not only chat consumption.
