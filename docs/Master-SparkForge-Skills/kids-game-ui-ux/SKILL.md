# Kids Game UI/UX

UI patterns for educational kids games: big affordances, audio cues, fail-soft UX.

## When to use this skill

- Building SparkForge Labs features related to: **Kids Game UI/UX**
- Prefer practices that repeated across recent YouTube sources (weighted below).
- Do **not** invent claims from videos without captions; weights come from captioned transcripts only.

## Weighted practice points

- **(weight 2)** Big buttons, clear affordances
- **(weight 2)** Character-guided navigation
- **(weight 2)** Fail-soft UX (undo, retry, no harsh fail)
- **(weight 2)** HUD simplicity for young players
- **(weight 1)** Color meaning & emotional design
- **(weight 1)** Minimize text; audio + visuals cue actions

## SparkForge application notes

- Learning goal first, then mechanics/UI chrome.
- Big targets, short sessions, fail-soft feedback, parent/teacher escape hatches.
- Privacy/COPPA by default; no dark patterns.
