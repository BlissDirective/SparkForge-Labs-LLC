# Forge motion / display morph brainstorm
(Product: LOCKED_HUB is welcome + main + control — no separate marketing hero.)
(Sparky: hologram/overlay — **no desk dock**.)

## Design principles
1. **One stage, many states** — same desk + SF emitter; only holograms / Sparky overlay / light change.
2. **Readable morphs** — forge rearranges for the kid; no camera jump-cuts.
3. **Sparky as guide** — overlay anchors (`nearSF`, `panelLip`, `whisperCenter`); can hop, point, ride beam.
4. **Empty glass → content** — idle = empty cyan glass; content wipes in on intent.

## State map
| State | Layout | Sparky overlay | Purpose |
|-------|--------|----------------|---------|
| **A Welcome** | Large C + 2 small *(or equal trio→morph)* | nearSF, idle wave | First land / home |
| **B Browse** | 3 destinations | Points at hover | Hub / Labs / Games |
| **C Focus** | C expands; sides yaw/tuck | Looks at C | Deep content |
| **D Dual** | Two mid; C strip | Between | Compare |
| **E Lab bench** | Wide work C; tool sides | Helps at tools | Make / edit |
| **F Game arena** | Stage C; score sides | Cheers at edge | Play |
| **G Whisper** | Panels dim | Dominates near SF | Coach tip |
| **H Emit burst** | Dissolve → reform | Rides SF beam | Mode change |
